\# LLM NPC Simulation



\## 概要

Unityと大規模言語モデル（LLM）を組み合わせ、NPC同士が自律的に会話するシステムです。



\## 制作目的

LLMを活用することで、NPC同士の相互作用から自然な会話や予測しきれない展開を生み出し、ゲームの面白さにつなげることを目指しています。



\## 使用技術

\- Unity 6

\- C#

\- Ollama

\- Llama 3



\## 主な機能

\- NPC同士の会話

\- LLMを利用した発話生成

\- 会話の進行管理
